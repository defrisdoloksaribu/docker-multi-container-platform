# Gambar Ilustrasi untuk Laporan

**Penting:** semua PNG di folder ini adalah ilustrasi/mockup yang dibuat untuk membantu tata letak laporan. Gambar-gambar ini **bukan screenshot dari laptop atau hasil pengujian aktual**, sehingga jangan digunakan sebagai bukti empiris. Sebelum laporan dikumpulkan atau dipublikasikan sebagai bukti pengujian, ganti setiap gambar dengan screenshot asli dari lingkungan proyek.

File yang disediakan:
- `container-status.png` — ilustrasi status container
- `api-health.png` — ilustrasi endpoint health
- `inventory-api.png` — ilustrasi respons inventaris
- `prometheus-targets.png` — ilustrasi target Prometheus
- `prometheus-cadvisor-query.png` — ilustrasi query cAdvisor
- `prometheus-memory-metrics.png` — ilustrasi metrik memori
- `grafana-dashboard.png` — ilustrasi dashboard Grafana
- `github-actions-ci.png` — ilustrasi halaman GitHub Actions
- `api-recovery-test.png` — ilustrasi pengujian pemulihan API

Angka, nama layanan, dan status yang tampak pada mockup bisa berbeda dari konfigurasi aktual.
